# Governance

protect-mcp is maintained by Tom Farley ([tomjwxf](https://github.com/tomjwxf))
through ScopeBlind. This is a maintainer-led project, not a foundation-governed
standard or a committee. The Acta Internet-Draft is a separate specification;
this repository's releases are not IETF endorsements.

## Decisions and releases

The maintainer reviews and merges changes, manages npm releases and handles
security reports. Significant API, receipt-format or dependency changes should
start as public issues describing the compatibility and operational effects.
Implementation and review occur in pull requests. Security reports use the
private process in [SECURITY.md](SECURITY.md).

Public contributions and downstream integrations are welcome. They do not imply
endorsement by the contributor's employer or a transfer of project governance.
Hosted ScopeBlind services are separate from this repository's open-source code.

## Participation

Use [CONTRIBUTING.md](CONTRIBUTING.md) to propose a change. Discuss technical
tradeoffs respectfully and provide reproducible evidence when reporting a bug.
Repeated contributors can discuss additional review responsibility with the
maintainer; no additional maintainer role or succession arrangement is promised
by this document. Current maintainer capacity remains a project dependency.
