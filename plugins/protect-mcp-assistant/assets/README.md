# Brand asset

`scopeblind-logo.png` is ScopeBlind's existing public GitHub organization
avatar, copied unchanged on 25 October 2026.

- [ScopeBlind organization](https://github.com/ScopeBlind)
- [Source image](https://avatars.githubusercontent.com/u/271959651?v=4)

The same 460 × 460 PNG is used for the plugin's listing logo and composer icon.
It is included in the package so installation does not fetch a remote image.
